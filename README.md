
# Atmosphere Audio Engine

**Процедурный аудио-движок на Python** для создания динамических звуковых ландшафтов, атмосферы и пространственного 3D-аудио в 2D-играх.

Проект разработан для симуляции атмосфер и адаптируется под любые нужды через JSON-конфигурацию.

---

## ✨ Возможности

*   **🌐 Пространственное 3D-аудио:**
    *   Автоматическое панорамирование (звук смещается влево/вправо в зависимости от положения игрока).
    *   Расчет затухания громкости в зависимости от дистанции.
    *   Плавная интерполяция (Lerp) громкости при движении.
*   **🎲 Умная генерация событий (Emitters):**
    *   Поддержка фоновых петель (Loops) и одиночных звуков (One-shots).
    *   **Алгоритмы вероятности:**
        *   `uniform`: Равномерный рандом (для фонового шума).
        *   `parabola`: "Живое" распределение (для природы/птиц).
        *   `linear_rise`: Нарастающее напряжение (для скримеров).
        *   `linear_fall`: Серийные звуки.
*   **🛠 Модульность:**
    *   Полное управление через JSON.
    *   Система "Dummy Assets": если звуковых файлов нет, движок сам создаст заглушки, чтобы код работал.
