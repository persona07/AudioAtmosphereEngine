# 🎧 Atmosphere Audio Engine

**Процедурный аудио-движок на Python** для создания динамических звуковых ландшафтов, густой атмосферы и пространственного 3D-аудио в 2D-играх.

Проект разработан для глубокой симуляции окружения и полностью адаптируется под любые нужды через JSON-конфигурацию.

---

## ✨ Ключевые возможности

### 🌐 Пространственное 3D-аудио
Движок эмулирует восприятие звука в пространстве:
*   **Автоматическое панорамирование:** Звук плавно смещается между левым и правым каналом в зависимости от положения слушателя.
*   **Distance Attenuation:** Реалистичный расчет затухания громкости при удалении от источника.
*   **Smooth Lerp:** Плавная интерполяция параметров — никаких резких скачков громкости при быстром движении.

### 🎲 Умная генерация событий (Emitters)
Система поддерживает как фоновые петли (**Loops**), так и одиночные звуки (**One-shots**) с продвинутыми алгоритмами вероятности:

| Алгоритм | Описание | Применение |
| :--- | :--- | :--- |
| `uniform` | Равномерный рандом | Общий фоновый шум, ветер |
| `parabola` | "Живое" распределение (Gaussian-like) | Природа, редкие крики птиц |
| `linear_rise` | Нарастающая вероятность | Нагнетание напряжения, скримеры |
| `linear_fall` | Убывающая вероятность | Эхо, осыпающиеся камни, серии звуков |

### 🛠 Полная модульность
*   Логика отделена от контента.
*   Все сценарии, зоны и звуки настраиваются через внешний **JSON**.

## 📦 Установка

### 1. Требования
*   Установленный **Python 3.8** или выше.
*   Менеджер пакетов `pip`.

### 2. Установка
Рекомендуется использовать виртуальное окружение, чтобы не засорять систему:

```bash
# Создание виртуального окружения (Windows)
python -m venv venv
# Активация
venv\Scripts\activate
```

```bash
# Создание виртуального окружения (macOS/Linux)
python3 -m venv venv
# Активация
source venv/bin/activate

```
Установите необходимые библиотеки из файла зависимостей:
```bash
pip install -r requirements.txt
```

## 🖥️ Консольный режим

Для запуска на серверах без графического интерфейса или для отладки логики предусмотрен специальный режим с **многопоточной архитектурой**.

### Запуск
```bash
python main.py
```

### ⚙️ Архитектура
Реализован паттерн **"Producer-Consumer"** для разделения логики ввода и обработки звука:

1.  **Main Thread (UI):** Блокируется функцией `input()`, ожидая команд пользователя. Пишет изменения в словарь `GLOBAL_STATE`.
2.  **Audio Thread (Worker):** Работает в фоновом режиме (демон).
    *   Каждые **50 мс** считывает `GLOBAL_STATE`.
    *   Обновляет физику движка и рассчитывает затухание.
    *   Переключает сцены и микширует звук.

> Это позволяет звуку меняться плавно и работать в реальном времени, даже когда терминал ожидает ввода текста.

### ⌨️ Команды консоли
В этом режиме вы управляете "виртуальным слушателем" через текстовые команды:

*   `list` — Показать список доступных локаций (ID).
*   `[name] [dist]` — Переместиться в локацию на заданную дистанцию.
    *   *Пример:* `forest 0` (Вы в центре леса, громкость 100%).
    *   *Пример:* `bunker 50` (Вы в 50м от бункера, звук тише).
*   `[dist]` — Изменить только дистанцию в текущей локации.
    *   *Пример:* `150` (Отойти на 150 метров).
*   `q` — Корректное завершение всех потоков и выход.
